# Manual test plan

Against <https://freelancer-tracking-system.web.app>.

Sign in with the account you created in the Firebase console. There is no
sign-up — if you cannot get in, add the user under **Build → Authentication →
Users**.

> **Before you start:** there is no way to delete a client, an order or an
> invoice from the UI — only individual payments. Anything you create while
> testing stays in your ledger permanently. See [Known gaps](#known-gaps).

## 1. Business details

Settings must be filled in before any invoice will print with a header.

- [ ] **Settings → Business details**, fill every field, Save. "Saved." appears.
- [ ] Reload the page. The values are still there.
- [ ] Leave the business name blank and save — it refuses with a message.

## 2. Clients

- [ ] Add a client with a **local-format** phone number (`077 123 4567`).
      The hint under the field should read *"WhatsApp will open +94771234567"* —
      the country code is added for you.
- [ ] Type a too-short number (`12345`). An error appears in red.
- [ ] Save, then **Edit** the client and change the name. The change sticks.

## 3. Multiple orders per client

- [ ] Create **three** orders for the same client, with different due dates:
      one in the past, one within a week, one months away.
- [ ] All three appear under that client.
- [ ] Each opens its own page with its own invoices.

## 4. Order lifecycle

- [ ] A new order starts at **Initial**.
- [ ] Step it through with the "Mark …" button:
      Initial → Confirmed → Started → Delivered → Payment pending → Completed.
- [ ] Jump straight to any stage with the dropdown.
- [ ] Set an order to **Completed** while money is still owed — a warning
      appears naming the outstanding amount.
- [ ] Pay an order in full while it sits at **Payment pending** — a note
      suggests marking it completed.
- [ ] Set an order to **Cancelled** — it leaves the dashboard totals.

## 5. Dashboard

- [ ] **Deliveries due** lists the past-due order as *Late* and the one within
      a week as *Due soon*. The distant one is absent.
- [ ] Mark the late order **Delivered** — it disappears from Deliveries due but
      stays in the active ledger while unpaid.
- [ ] **Needs chasing** lists unpaid invoices due within three days.
- [ ] The four figures at the top add up: Outstanding, Collected, Your payout,
      Book of work.
- [ ] Every amount reads **Rs**, never `$`.

## 6. Billing types

Create one order of each type and check the invoices it raises:

- [ ] **Fixed (split)** — two invoices, half each.
- [ ] **Milestone** — none; add them yourself, each with Qty/Description/Rate.
- [ ] **Monthly retainer** — this month only. "Generate next month" adds the
      next. Generate a second month while the first is unpaid: a warning says a
      previous month is still unpaid.
- [ ] **Pay on delivery** — a single invoice.

## 7. Payments

- [ ] Log a **part** payment. The invoice reads *Partially Paid* and the
      balance drops by that amount.
- [ ] Log the remainder. It reads *Fully Paid*.
- [ ] Log a payment with **"Money has landed" unticked**. The balance drops but
      *Your payout* does not — it shows "pending clearance".
- [ ] Press **Mark cleared**. The payout catches up.
- [ ] Delete a payment with ✕. The balance goes back up.
- [ ] Overpay an invoice. It shows as a credit, not a negative.

## 8. Invoices

- [ ] On an order, press **Invoice**. The sheet shows your business header,
      the client under M/S, and the line items.
- [ ] Total / Paid / Balance match the order page.
- [ ] Press **Print / Save as PDF**. The app chrome disappears, the page fits
      A4, and the green banner and coloured total rows are still there.
      *If the colours print white, enable "Background graphics" in the print
      dialog.*
- [ ] An invoice with no line items still prints, using its label as one row.

## 9. WhatsApp

- [ ] Press **Request** on an unpaid invoice. WhatsApp opens with the message
      filled in and the correct number. **Do not send it to a real client.**
- [ ] Press **Remind** on the dashboard, and **Receipt** on a logged payment.
- [ ] Check the amounts in the message text read Rs.

## 10. Mobile and dark mode

- [ ] Open the site on your phone. Nothing scrolls sideways; wide tables
      scroll within themselves.
- [ ] Switch your phone to dark mode. Text stays readable everywhere.

## Known gaps

Not bugs — things this phase does not do:

- **Nothing can be deleted except payments.** No delete for clients, orders or
  invoices, so test data is permanent.
- **No WhatsApp automation.** Every message is opened for you to send by hand.
- **No scheduled reminders.** The dashboard lists what needs chasing; nothing
  is sent automatically.
- **Retainer months are generated by a button**, not on the 1st automatically.
- **One account.** No sharing, no second user.
